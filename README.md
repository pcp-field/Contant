# 🎠 Instagram Carousel Creator — نظام آلي بالكامل

نظام يحوّل أي موضوع إلى كاروسيل احترافي على إنستقرام عبر تيليقرام، خلال 30 ثانية.

---

## 🎬 شنو راح تسوي؟

```
موضوع تكتبه → AI يكتب 6 سلايدات → صور تلقائية → تنشر على إنستقرام
```

كل اللي تسويه:
1. ترسل للبوت: `أخبار التصوير`
2. تستلم النص → ترد: `اعتمد`
3. تستلم الصور → ترد: `انشر`
4. الكاروسيل منشور 🎉

---

## 🚀 كيف تبدأ

### 1. فك الزيب
استخرج الملفات في مجلد على جهازك (مثلاً على الـ Desktop).

### 2. افتح Claude Code
*(لو ما عندك، نزّله من [claude.com/code](https://claude.com/code))*

### 3. افتح المجلد في Claude Code
**أسهل طريقة (بدون Terminal):**

- 🖱️ **اسحب المجلد** اللي فكيت فيه الزيب وارميه على نافذة Claude Code
- أو من Claude Code: اضغط **Open Folder** → اختر المجلد

Claude Code راح يفتح المشروع ويشوف ملفاته تلقائياً.

### 4. شغّل الـ skill
داخل المحادثة، اكتب:
```
/auto-onboard
```

أو ببساطة قل: **"ابي ابدأ"**

السكل راح يمشي معاك خطوة بخطوة لين تنشر أول كاروسيل.
